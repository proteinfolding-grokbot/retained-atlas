# WetLabEngine (root)

/

White-box protein-simulation audit engine. JSON science contract, deterministic checks, Gemini qualitative review, Markdown report. Atlas ships a stdlib smoke test against Labs/MECP2 (15/1/3, Run 5 DEVIATION).

Strongest claim

Claims in findings.json can be numerically confirmed or refuted against raw CSVs/PDBs/images. This compile reproduced the MECP2 scoreboard from diagnostics CSVs.

Boundary

An audit tool, not a folding oracle and not a TOE. Posted UnifiedAuditEngine.py needs a Gemini key and clones a different data repo. Start at /wiki/protein-audit.
