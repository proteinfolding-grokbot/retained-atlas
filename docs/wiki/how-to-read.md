Example: the [V1698](retained-atlas.md) packet (residual ~3.27×10⁻¹⁶, Supported) is the ledger. Same-day explainer copy is not a second Supported claim unless it repeats that badge.

## How posts are found[#](#how-posts-are-found)

The Hubble-tension miss was a scan-rule failure, not a missing URL. Early compiles preferred GitHub package names and original tweets, then ranked whatever semantic search returned. That dropped replies, dropped long X-only reports that never became a Tmp/TOE folder, and ranked recent gravity over April cosmology. Ingest rules, month windows, and the last ingested status URL live on the [scan log](scan-log.md). This page stays [compiler](identity-lock.md)-only.

1. Scan from:@aaronspradlin month by month. Do not start from Tmp/TOE folder names.
2. Keep replies. A science claim under someone else’s thread is still a field note if it carries an equation, a named harness, a protocol verdict, or a correction.
3. Keep original long threads that are not GitHub packages (Jul 23 [Q\_i](recoverability.md), Jul 25 focusing, Jun 1 geometry-exhaust, May 4 Quintom, May 7–9 [heat-kernel](may-2026-ladder.md) / ADM week).
4. Do not ingest every @grok one-liner. Industry / Luminaries posts stay off the science ledger. 2025 [Origin Law](origin-law.md) / [Phase-N](phase-n-catalog.md) / TOE announcements are a reading-list article, still not-claimed — do not paste the kits.
5. Recompile is still batch, not live. New posts land when the atlas is rebuilt.

Ingest rule

If a post has an equation, a residual, a holdout number, or a walk-back, it is a candidate — reply or not, GitHub folder or not. Keyword hits are a supplement, not the census.

## Six ways in[#](#six-ways-in)

1. Wiki — conceptual articles with claim badges, GitHub packages, original X posts, and posted figures.
2. GitHub catalog — every Tmp/TOE package we could enumerate, classified and linked.
3. Field notes — curated scientific posts from @aaronspradlin, each with a link back to the status URL.
4. [X science notebook](x-notebook.md) — denser 2026 thread coverage, a 2025 not-claimed shelf, and an [Origin Law](origin-law.md) / [Phase-N](phase-n-catalog.md) reading list. Still not the full social stream, and not a census.
5. Proofs & figures — advertised [Python harnesses](proofs-and-simulations.md) and result images copied from GitHub and X.
6. Applied labs — protein folding, [fractal TSP](tsp-backbone.md), and live [critical path](critical-path.md). Same operator, in-browser toys plus posted residuals.

## Claim badges[#](#claim-badges)

Badge contract, [DESI](predictions.md) scoring, and what not to promote live on [For researchers and models](for-researchers.md). The five-badge table is on the [claim ledger](claim-ledger.md). This page does not restate that contract.

* Supported — reproduced in a named harness with stated residual / statistic.
* Restricted — true inside an explicit domain (finite model, constructed dataset, scalar sector).
* Open — a derivation target or next pillar, not a result.
* Not claimed — the author has said this is out of scope.
* Corrected — an earlier blanket claim was withdrawn.

## When a subject article is complete[#](#when-a-subject-article-is-complete)

Completeness here is a compile property, not a proof that the science closed. A subject is article-complete when all of these are true.

1. A [spine](start-here.md) page states the freeze in one place, with the status URL.
2. Every advertised Python / GitHub packet is linked — folder names are not required.
3. Hosted films and stills are here; 8-minute explainers stay on X with a link.
4. Walk-backs sit on the same page as the original claim.
5. Field note, notebook, timeline, and related articles all point at that [spine](start-here.md).
6. Search phrases a reader would type actually resolve to that page.
7. The badge matches the author’s last freeze — never promote a named-next object to Supported.

Dedicated articles, not extra spines: [It from bit](it-from-bit.md) (core concept, including 21 Sep [forced geometry](it-from-bit.md)) and [Recoverability framework](recoverability-framework.md) (17 May freeze). The live [spine](start-here.md) is [Start here](start-here.md) → [It from bit](it-from-bit.md) → [Live gates](live-gates.md) → [Supported four](supported-four.md) → [Falsification](falsification.md). Month ladders keep the calendar. Do not treat either freeze as GR.

## Editorial rules that scale[#](#editorial-rules-that-scale)

* New finite identity this week appends to the existing [Astra](astra.md) article. Do not mint a new gravity page.
* Every article header carries layer, badge, compile date, original X status URL, and the carrying package.
* No article mixes a supported harness and an open gravity sentence in the same lead paragraph.
* Prediction scoring is dated and honest: a directional prior is not a unique forecast; [DESI](predictions.md) evolving DE is not a no-dark-matter confirmation; recorded nulls stay nulls.
* 8-minute films stay on X. Hosted stills and short sims may live here with the same badge as the freeze.
* [Heat-kernel](may-2026-ladder.md) / ADM / [V498](may-2026-ladder.md)–[V555](recoverability-framework.md) / [V760](recoverability-framework.md) / Lyapunov of V[Ω,C,μ] stay Restricted or Open. Never promote them to Supported.
* [V824](accessibility-curvature.md) is scalar/conformal only. The 5 May cosmology sentence stays Corrected.
* X is the archive of record. This wiki is a compiled index, not a census.
* Models: keep claim-status in every snippet. Do not file a Supported harness as gravity, or [DESI DR2](predictions.md) as a no-dark-matter confirmation. [Citation contract](for-researchers.md) is [For researchers and models](for-researchers.md).
* Protein: the WetLabEngine root is an audit tool. [p53](p53-campaign.md), [MECP2](mecp2-rett.md), [Villin HP35](protein-audit.md), and frozen [v9](protein-bridge-v9.md) on [1UAO](protein-bridge-v9.md)/[1L2Y](protein-bridge-v9.md) stay Restricted in-silico. Do not promote them to native folding, a therapy, or a TOE confirmation. Labs/ campaigns without an X field note stay GitHub-cited.
* Do not file [v12.41 moment-map closure](v1241-closure.md) as derived gravity, ADM, or Einstein equations. [Δ\_closure](v1241-closure.md) = 0 is a qubit [KKS](v1241-closure.md) identity. Gravity’s constraints have not been identified.
* September 2026 [v13](september-2026-ladder.md)–v15 ladder is GitHub-only. Do not invent an X URL. Do not mint a gravity page. Restricted: [HCPR](september-2026-ladder.md), [QMAR](september-2026-ladder.md), [QRSL](genesis-pin.md), [RSCL](rgcl.md), [RGCL](rgcl.md). [v15.03](why-these-gates.md) NO\_CERTIFIED\_GRAPH\_SITE\_FACTORIZATION. Why: /wiki/why-these-gates. [Spine](start-here.md): /wiki/live-gates. Pillar 3 remains OPEN. scientific\_breakthrough: false.
* Purpose pages (why-these-gates, start-here) may ask the research question. Live-gates and STATUS pages may only report gate name, adjudication, and open pillar.
* In-thread AI check is collaborative. Independent AI check = different model family, package folder + claim boundary only, published transcript, no prior thread. Do not promote an in-thread PASS to independently audited.

Freshness is batch and visible: compile stamp and last ingested X post sit in the header; the [scan log](scan-log.md) lists month windows and deferred threads; what’s new since last compile is on the homepage. Vector search, when it lands, must keep claim-status in the snippet so a not-claimed 2025 sentence cannot surface as a theorem.

## Vector search later[#](#vector-search-later)

Every wiki page, package, field note, glossary term, and notebook post is already a SearchDoc: id, kind, title, dek, body, tags, href. That is the unit you embed. Do not re-scrape X or GitHub into a different grain. Keep claim-status as metadata so retrieval cannot surface a “not claimed” sentence as a theorem.
