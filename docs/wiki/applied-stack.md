One operator, three labs

Preserve what remains coherent. Deform what is stressed. Reset only what became stale. Posted as recurrence across domains that should not casually rhyme. The 10 May question — what equation unifies them — is still open.

applied\_recoverability\_operator.py (pedagogical reconstruction)

[Open source](../data/artifacts/py/applied_recoverability_operator.py)

```
def recover(G, R, shock, tau_lo=0.25, tau_hi=0.72):
    stress = strain(G, R, shock)
    keep   = G[stress < tau_lo]           # preserve
    warp   = deform(G[(stress >= tau_lo) & (stress < tau_hi)], R)
    reseed = reset(G[stress >= tau_hi])   # only the stale
    return splice(keep, warp, reseed)
```
