The question being tested — Open, not found

How much of gravity-like structure is unavoidable once global quantum relational consistency is taken seriously? Gravity’s universality may be inherited from that law. That is a thesis under test. It is not a Supported result. Einstein remains the effective fact in a retained world. scientific\_breakthrough: false.

The primitive layer is atemporal. Global relational compatibility comes first. Pruning is intended to generate ordering and, later, time. Before pruning, the work asks what structure is already forced by quantum consistency alone. We do not want to make that thesis true by choosing functions that happen to reproduce gravity. That is why the gates exist.

## What is already earned, conditionally[#](#what-is-already-earned-conditionally)

If an appropriate operator-valued source P is supplied, [v14.03](compatibility-lab.md) remains certified: [P] → X\* → [g] on the archived support. That is a dual response on the boundary of an admissible state space. It is not Einstein, not ADM, not a metric. Conditional on P.

The live scientific question is: where does P itself come from? Do not insert P by hand because a dual ray would then look gravity-like.

## One upstream attack (Git, 12–13 Sep)[#](#one-upstream-attack-git-12-13-sep)

1. [v14.04](september-2026-ladder.md) — ordinary scalar provenance cannot become the required noncentral operator. Independent local-frame covariance forces a state-independent lift into the scalar center, which is PGRL-null. The source cannot be “the graph scalar written as a matrix.”
2. [v15.01](representation-gap.md) — provenance and the compatibility calculation are not secretly the same parent. C^125 → C^25 support is exact; no canonical provenance operator lives there.
3. v15.02 — five graph nodes and five quantum labels. Matching cardinality is not an identification. 120 inequivalent bijections. Nothing earned chooses one.
4. v15.03 — perhaps a graph node is a quantum subsystem, and the site state supplies the missing direction. State context permits covariant noncentral lifts. Several lawful state functions give different source rays. Existence without uniqueness. Five nontrivial sites cannot equal the C^125 parent. NO\_CERTIFIED\_GRAPH\_SITE\_FACTORIZATION.

These are not disconnected exercises. Each gate closes a place where a gravity law could be smuggled in. Negative results are the method.

If it does not, an operator-valued source principle is an irreducible new axiom at this layer — labeled NEW ASSUMPTION, justified before seeing gravity, never chosen because it looks Einstein-like.
