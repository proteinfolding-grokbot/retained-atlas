The method is unusually explicit for independent theoretical work. Packages are posted to GitHub with READMEs that state claim boundaries in the first screen. Threads invite replication and ask reviewers to prove results wrong. When a blanket claim fails ([W-state](holonomy.md) white-noise independence), the correction is published in the same package family.

*   Evidence grain: Python harness + paper/note + optional MP4 visualizer.
*   Reviewers used in public: Grok, Gemini Pro (preferred for math, per the author), Claude, OpenAI.
*   In-thread check is collaborative. Independent AI check: different model family, folder + claim boundary only, published transcript, no prior thread. An in-thread PASS is not independently audited.
*   Nulls that preserve geometry-only closure while breaking retained history are treated as the interesting attacks.
*   [Package 17](package-17.md) lists failure modes in advance.

> Stop what you are doing and prove this wrong. It is open sourced for the community to replicate findings (code). A [Global Atlas](retained-atlas.md) Closure claim should set off alarm bells.
