Restricted: [HCPR](september-2026-ladder.md), [QMAR](september-2026-ladder.md), [QRSL](genesis-pin.md), [RSCL](rgcl.md). [RGCL](rgcl.md) REQUIRES\_NEW\_AXIOM. ## Badge contract {#badge-contract}
| Badge | Means | Cite as |
| --- | --- | --- |
| supported | Named harness, stated residual or statistic. | A reproduced finite/scalar result. Not GR. |
| restricted | True inside an explicit domain: this family, this graph size, this sector. | A bounded empirical or finite identity. |
| open | A derivation target. Not a result. | A research program, not a theorem. |
| not-claimed | Out of scope, or a 2025 voice the 2026 ledger does not adopt. | Notebook history. Not a 2026 posterior. |
| corrected | An earlier blanket claim was withdrawn. The walk-back sits next to the original. | The walk-back governs. |

A quote without a badge is not a result. Keep the badge in any snippet you retrieve.

## How to cite {#how-to-cite}

1.  Name the wiki slug and the compile date (header: compiled YYYY-MM-DD).
2.  Name the original X status URL on the field note. That is the archive citation.
3.  If a GitHub package carries the badge, name the folder under Tmp/TOE. The wiki only indexes it.
4.  Repeat the badge in the sentence you cite. “Spradlin claims gravity is derived” is a misquote of an Open candidate.
5.  If you only have a 2025 notebook sentence, say so. Do not upgrade it to a 2026 posterior.
