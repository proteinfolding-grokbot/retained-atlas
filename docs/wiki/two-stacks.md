Do not glue these

[v15.01](representation-gap.md)–[v15.03](why-these-gates.md): these stacks are not the same typed object. Cardinality “5 = 5” is not a functor. A graph node is not a certified quantum site. Do not draw one diagram that pretends they are glued.

What you lose if you combine them

Stack A owns the June causal ladder ([Astra](astra.md) → Pin → prune → slice → L1–[L4](causal-stack.md) → [V1698](retained-atlas.md)/[V824](accessibility-curvature.md) → [Package 17](package-17.md)). Stack B owns the Sep representation ladder ((5^{⊗3}) parent → pair fiber → hidden kernel → supplied [P] → [g]). Do not draw one arrow. If you combine them, the claim is Not claimed — not Restricted, not Supported.
