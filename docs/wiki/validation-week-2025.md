Same thread: a DES/HSC/CFHTLenS/KiDS/RCSLenS + SDSS DR17 + Chandra/XMM mass-scaling chart. The chart used an unfilled Python placeholder for fit coefficients; this atlas does not invent them. 30 Jan posted the ICL-growth equation.
